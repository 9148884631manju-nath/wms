# 🛒 E-Commerce Engine with Excel Integration

A lightweight PHP e-commerce platform integrated with **PhpSpreadsheet** for seamless product catalog updates, batch category management, inventory imports, and sales reporting directly via Excel files (`.xlsx`).

---

## 🚀 Key Features

* **Excel Data Management:** Update categories, prices, inventory, and product titles directly using Excel file row/column mapping.
* **Modern HTMX UI:** Dynamic, reactive admin interface featuring modal popups and asynchronous CRUD operations without page reloads.
* **Tailwind CSS Styling:** Fully responsive, modern visual components with sleek dark/light theme support.

---

## 🛠️ Prerequisites

Ensure your system meets the following requirements before installation:

* **PHP:** Version `^8.1` or higher
* **Composer:** Installed globally
* **PHP Extensions:** `ext-zip`, `ext-xml`, `ext-gd`, `ext-mbstring` (required by PhpSpreadsheet)
